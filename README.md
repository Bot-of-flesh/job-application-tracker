# 応募先・選考状況管理アプリ

応募先の会社と選考状況を管理するWebアプリです。ターミナル版から作り始め、FlaskとSQLiteでWeb版にしました。

[公開デモを開く](https://chipmonkey300.pythonanywhere.com/)

このデモでは、登録内容をすべての閲覧者が閲覧・変更・削除できます。架空の会社名でお試しください。

## できること

- 応募先を登録し、一覧で見る
- 選考状況を変更し、状況ごとに絞り込む
- 登録した会社を1社ずつ削除する

## AIを使ってどう作ったか

AIに課題を小さく分けてもらい、詰まったときはヒントをもらいながら、自分でコードを書きました。書いたコードのレビューや、テスト用DBでの動作確認もAIに手伝ってもらいました。

たとえば、30社に達すると次の人が登録を試せなくなることに気づき、会社を1社ずつ削除できるようにしました。AIの助けを借りて、30社の状態から1社を削除し、再登録できることを確認しました。
